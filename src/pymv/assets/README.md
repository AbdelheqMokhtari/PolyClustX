# Provisional identity

`logo.png` was generated using the built-in image-generation tool for this
documentation/interface redesign. It is a provisional, independent library
symbol, not a Université Paris Cité logo or endorsement.

Prompt: a symbol-only, minimal scientific multi-view mark; three overlapping
geometric panels converging on a shared center; burgundy #8A1538, slate #475569,
white background; no letters, numbers, watermark or mockup.

Use the same asset in Sphinx and the workbench. The UI palette uses #8A1538 as
a restrained accent, #334155 for text, #F8FAFC for surfaces and #E2E8F0 borders.
