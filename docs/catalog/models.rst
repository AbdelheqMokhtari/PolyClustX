Available models
================

This table is built from the model registry, so registered methods appear
automatically when the documentation is rebuilt.

.. pymv-catalog:: models

Both current implementations accept one, two or several complete feature views.
LMGEC uses graphs when preprocessing is enabled; SCM accepts but ignores them.
Neither currently implements native incomplete-view optimization. Explicit
imputation is a baseline, not a claim about the papers.

Constructors and learned attributes are documented in :doc:`/api/models`.
For background and citations, see :doc:`/background/algorithms`.
